# Простые примеры паттернов проектирования на java
## Добавление примеров, структура папок
Для единообразия запуска храним пакеты в папках src/<Имя паттерна>/<Имя примера>
Компилируем и запускаем пакеты из папки src

## Компиляция
Для компиляции запускаем из папки src компиляцию с указанием файла, содержащего main
```bash
javac observer/weatherstation/WeatherStation.java  
```
В папке пакета после компиляции появятся файлы .class

## Запуск
Для запуска запускаем из папки src файл, содержащий `main`
```bash
java observer/weatherstation/WeatherStation
```
В терминале запустится пакет
